# Security Policy

Please do not report credential exposure or security vulnerabilities in a public issue.

Until a private advisory channel is configured, contact the repository maintainers privately with:

- affected version or commit
- impacted command/API route
- reproduction steps without credentials
- security impact
- suggested mitigation, if known

Never send API keys, bearer tokens, cookies, or private deployment URLs in the report. Revoke any credential that may have been exposed before reporting.

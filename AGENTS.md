## Agent skills

### Issue tracker

GitHub Issues; external PRs are also a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default five labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: root `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
